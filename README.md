# Software Engineering Playground

A personal repository for practicing and reviewing software engineering and computer science concepts.

## Topics

- **Data Structures & Algorithms** — Problem-solving, algorithmic techniques, and coding interview preparation.
- **Software Engineering** — Design patterns, clean code, testing, and best practices.
- **System Design** — Software architecture, scalability, and distributed systems.
- **Computer Science Fundamentals** — Operating systems, networking, databases, and other core concepts.

## Coding Practice

Algorithm and data structure solutions are primarily practiced through [NeetCode](https://neetcode.io/) and [LeetCode](https://leetcode.com/).

Some solutions are automatically synchronized using the **NeetCode GitHub Sync** integration.

## Purpose

- Strengthen my software engineering fundamentals.
- Improve problem-solving and algorithmic thinking.
- Prepare for technical interviews.
- Explore new concepts through hands-on practice.
- Maintain a personal knowledge base for future reference.
